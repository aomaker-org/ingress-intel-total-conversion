# Dev Template Project (50811_dev_template)

This repository contains a development template for bootstrapping new projects.

## Structure

- `Jules/`: Contains notes, logs, and other artifacts related to the AI developer Jules.
- `docker/`: For Docker-related files and configurations.
- `codespaces/`: For GitHub Codespaces configuration.
- `cicd/`: For CI/CD pipeline configurations.
- `prompts/`: A collection of prompts for AI models.

## Assumptions

- Fast prototyping with low friction to commit.
- All assumptions are logged.
- Best practices are followed.
- Sources and references are attributed.
